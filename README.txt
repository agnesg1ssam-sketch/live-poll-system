LIVE POLL SYSTEM - 여러 교사 사용 버전

핵심 기능
- 교사가 새 수업 만들기 클릭
- 6자리 수업 코드 자동 생성
- 학생용 링크와 QR코드 자동 생성
- 여러 교사가 서로 다른 수업방을 동시에 사용
- 투표 1, 2, 3
- 학생에게 결과 공개
- 실시간 의견 톡
- 결과와 의견 PDF 저장

중요
이 버전은 여러 기기에서 사용하므로 반드시 웹에 올려야 합니다.
컴퓨터에서 teacher.html을 더블클릭하면 기능 테스트는 가능하지만,
학생 휴대폰이 그 파일 주소로 접속할 수는 없습니다.

가장 쉬운 배포
1. GitHub 저장소를 새로 만듭니다.
2. 압축을 푼 파일 전체를 업로드합니다.
3. Settings > Pages에서 main / root를 선택합니다.
4. 생성된 주소를 교사들에게 공유합니다.

Firebase 규칙
Firebase 콘솔 > Realtime Database > 규칙에서
database.rules.json 내용을 붙여 넣고 게시합니다.

교사 사용 순서
1. teacher.html 접속
2. 새 수업 만들기
3. 뉴스 제목과 댓글 입력 후 저장
4. QR 또는 링크를 학생에게 공유
5. 투표 1 → 투표 2 → 투표 3 → 결과 공개 → 의견 톡
6. PDF 저장
7. 수업 종료 후 수업방 삭제

주의
현재 버전은 편의성을 위해 별도 교사 로그인을 사용하지 않습니다.
수업 코드를 아는 사람은 해당 수업방에 접근할 수 있으므로
민감한 개인정보는 입력하지 마세요.
